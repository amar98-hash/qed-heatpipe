# light-matter-heatpipe-tube
This is a C++QED based project. The project is developed to simulate the density matrix evolution of a tube of hot metal vapour in Argon background.
This is a direct next step after the ASL-based heatpipe simulation developed in another project [add git repo of the heatpipe project later].
This project is roughly designed in three major sections:
## Thermodynamic Equillibrium Tube of Hot Ar gas and Alkali matal vapour.
1. Cylinder of gases with r and L cylinder radius and length.
2. Gaussian intensity profile of laser light(s).
## Lindbaldian of the Qunechers as open-quantum system.
1. Add statistical contribution and couplings from Ar and Alkali number densities.

## Goal
1. To calculate the spatially resolved density matrix $\rho(\vec{r}, v, t)$.
